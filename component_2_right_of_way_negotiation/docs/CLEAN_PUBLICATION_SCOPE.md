# Clean publication scope

This branch was prepared from the latest local working files without rewriting the original repository.
It retains Component 2 source, tests, documentation, intention ONNX assets, selected E5 MAPPO checkpoint, final evaluation reports/plots, panel summaries, and the original authentic Scenario 5 collision recording.

Large JSONL traces, repeated runtime snapshots, browser rehearsals, training development outputs, caches, virtual environments and duplicate ZIP archives were intentionally not published. Full archive/diagnostic verification tools that depend on those historical raw files require the original evidence archive. Evaluation summaries remain unchanged; the website reports archive verification unavailable when the full archive is absent.

Component 1 and Component 3 were empty locally and are represented by explicitly labeled placeholder documentation. This branch does not contain their implementations or a CARLA server; external Component 3 endpoints must still be provided separately.

Install the showcase and Component 2 dependencies in a separate environment, install SUMO, and follow the existing READMEs. No Python, UI, model, controller or research configuration has been changed for publication. Only the publication copy's ignore files were corrected.
