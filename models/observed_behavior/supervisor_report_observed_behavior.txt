Professional V2V LSTM Observed-Behaviour Report
================================================================================

Why the previous 98% accuracy was suspicious:
The previous dataset used deterministic rule-generated labels and included features directly related to those same rules. The model could therefore learn the rule rather than real driving behaviour.

Main improvements in this notebook:
1. All recordings 07-17 are processed.
2. Parked/static/short tracks are removed.
3. Intersection center is estimated after moving-vehicle filtering.
4. Maneuver is inferred using trajectory segments, not only first/last frame.
5. Labels are generated from future observed vehicle motion, not current V2V rule output.
6. Leakage columns such as previous GO/YIELD counts are not used as model features.
7. Recording-wise split keeps recordings 16-17 unseen for final testing.
